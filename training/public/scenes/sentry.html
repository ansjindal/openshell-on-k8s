What is an agent?

A model answers a question. An agent works toward a goal on its own, using tools, for minutes or days.

Give it a goal and its harness loops: think, act, check the result, repeat.

Agents are everywhere

They browse, call APIs, write code and move data on their own, around the clock.

Each one works with real credentials.

Without a boundary, an agent can reach anything its host can.

One poisoned page

Agents act on what they read, and they can’t always tell data from instructions.

One hidden line on a web page is enough to turn a helpful agent against you.

An agent can’t be trusted to police itself. The boundary has to sit outside it.

Drop it into OpenShell

NVIDIA OpenShell gives every agent its own sandbox around files, processes and network.

You write the policy in a short file. Anything it doesn’t allow is denied.

A trusted supervisor decides every connection. The agent can only ask.

When the host is compromised

OpenShell’s supervisor runs on the same host as the agent.

With root on that host, an attacker can stop it, rewrite the policy and wipe the logs.

The referee has to live where the host can’t reach.

Raise the Sentry tower

NVIDIA Sentry moves the network decision onto BlueField-4, with its own CPU and operating system.

DOCA Tower enforces the same OpenShell policy. DOCA Argus tells it which program sent each request.

Root on the host can’t rewrite either of them.
