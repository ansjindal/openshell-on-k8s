In Module 1 you sealed one agent. This module makes agents your own and then runs them like a platform: **first as the agent developer**, you give an agent credentials it never sees, a persona, skills from a registry you control and real tasks; **then as the security reviewer**, you follow every decision into the audit trail, drive the same gateway from the web console, and give people roles and workspaces.
