<Optional title="Why not just set an environment variable?">
An agent that can read its token can also send it anywhere: in a URL, a log line, or a request a prompt injection asked for. With a provider the sandbox only ever holds a placeholder, and the real value exists only inside the supervisor, on requests that match the profile.
