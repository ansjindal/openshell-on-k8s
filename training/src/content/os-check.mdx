## What you learned

- **An agent is a model plus a harness that acts with your access.** One poisoned input can steer it, so the guardrail has to sit outside the agent's process, where it can't be argued with.
- **OpenShell puts the agent in a sandbox: a workload pod and a supervisor pod.** The gateway stores workspaces, providers and policies; the supervisor decides every connection and holds the real keys, so the agent only ever sees placeholders.
- **The policy is deny by default.** Files, Landlock and the user are fixed at start; network rules change live, per host, port and program (L4) and per method and path (L7), and each change is a numbered revision.
- **Every decision is on the record**, as an OCSF event in the sandbox's log.
