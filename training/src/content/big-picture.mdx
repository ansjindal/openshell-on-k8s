## Each component in a sentence

- **k3s**: single-node upstream Kubernetes. Lightweight, but a real cluster: the same CRDs, RBAC, NetworkPolicy and scheduler you'd use anywhere. The kubeconfig is `/etc/rancher/k3s/k3s.yaml`.
- **agent-sandbox controller**: [kubernetes-sigs/agent-sandbox](https://github.com/kubernetes-sigs/agent-sandbox). It reconciles each `Sandbox` custom resource (`agents.x-k8s.io`) into a pod, the way a Deployment controller reconciles ReplicaSets.
- **OpenShell gateway** (namespace `openshell`): the control plane. It creates sandboxes, stores their policies and provider credentials, and decides who may do what. The CLI reaches it on NodePort **30808**.
- **Sandboxes** (one namespace per workspace, e.g. `openshell-lab-default`, created by the gateway): each one is **two pods**, the agent's workload pod and its supervisor pod. The supervisor owns the agent's network.
- **LiteLLM** (namespace `litellm`): one OpenAI-compatible endpoint in front of the model. Agents reach it through the `litellm` **provider**, with a key they never see.
- **Keycloak**, **Envoy Gateway** and the **OpenShell Console**: people sign in with Keycloak; Envoy publishes the training site, Keycloak and Grafana on one host and the console on its own.
- **Monitoring**: Prometheus and Grafana for metrics, Loki for logs and OpenShell's audit events, Tempo for traces.
- **OpenClaw 🦞**: the default agent, baked into the default sandbox image `ghcr.io/ansjindal/openshell-on-k8s/openclaw-sandbox`.

## The flow, end to end

Press **Next** to build one sandbox on Kubernetes in deployment order: LiteLLM, observability, Keycloak, the OpenShell chart, a workspace, then the sandbox. The agent reaches its model only through the supervisor and LiteLLM.

<DeckScene src="openshell" only="k8s" title="One sandbox on Kubernetes" />

You ask the gateway for a sandbox. It writes a `Sandbox` resource and starts a supervisor pod; the controller turns the resource into the workload pod running OpenClaw. The workload pod can only talk to its supervisor. When the agent calls LiteLLM, the supervisor checks the request against the sandbox's policy, swaps the placeholder in `Authorization` for the real key, and forwards it.

<Callout type="note" title="The mental model">
A sandbox is a pair of pods plus a policy. Creating an agent means creating a sandbox; deleting it tears both pods down. Everything else, isolation, policy, credentials and audit, hangs off that.
</Callout>
